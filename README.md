# Tilawah

A simple Quran reading tracker. Tap a juz when you finish it, pick any date, and count your khatams. Data stays in your own browser.

Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

Publish: upload all files to a new public GitHub repository, then Settings > Pages > Branch main, folder / (root).
